# Hardware Evaluation — authoritative source

**`MIRACLE/` is the single authoritative source** for all hardware results in the
paper. Runs performed 2026-06-20 on RPi 4B with MIRACL Core (NIST P-256),
governor pinned, energy = wall × 3.8 W, per-round (warm-up discarded).

Authoritative Auth+KeyEx per-round numbers (median of 7 runs):

| Scheme | Energy (J) | Time (s) |
|---|---|---|
| Proposed | 0.0617 | 0.0162 |
| DAuth | 0.0611 | 0.0161 |
| LAAKA | 0.0959 | 0.0253 |
| Zhou | 0.1074 | 0.0282 |

- Paper figure `fig_hw_comparison.png` is generated by `MIRACLE/plot_auth_keyex.py`
  (writes to both `MIRACLE/` and `Paper/`).
- Summary: `MIRACLE/Authentication&KeyExchange_HW.md`; end-to-end: `MIRACLE/E2E_README.md`.

`_archive_pre_miracle/` holds the earlier (pre-MIRACLE) hardware scripts, charts,
and per-scheme run data. These contained inconsistent values and are retained only
for history — **do not cite them**.
